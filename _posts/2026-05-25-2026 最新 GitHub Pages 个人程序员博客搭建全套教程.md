一、前言
GitHub Pages 是 GitHub 官方提供的免费静态网站托管服务，无需服务器、无需域名费用、稳定高速，是程序员搭建个人技术博客的最优选择。
本教程从零开始，完整覆盖：用户名配置、仓库创建、Jekyll初始化、分类标签配置、评论功能集成、日常发文规范，一次性搭建完成可长期使用的个人技术博客。
二、前期准备工作
2.1 注册/完善 GitHub 账号
1. 注册 GitHub 账号，完成邮箱验证
2.修改GitHub用户名（核心关键）
路径：头像 → Settings → Account → Change username
建议使用实名拼音用户名：yangzhaozhou（全小写、无特殊符号）
⚠️ 重要规则：GitHub Pages 个人博客强制要求
- 仓库名必须严格等于：用户名.github.io
- 博客最终访问地址：https://用户名.github.io
2.2 安装 Git 工具
Windows/Mac/Linux 安装 Git，用于本地代码提交、推送博客文件
安装完成后终端输入 git --version，显示版本号即为安装成功。
2.3 配置 SSH 密钥（解决权限报错）
避免每次推送输入账号密码，彻底解决 Permission denied 权限问题
1. 生成密钥（替换为自己的GitHub邮箱）
ssh-keygen -t ed25519 -C "你的GitHub邮箱"
2. 启动密钥代理并添加密钥
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
3. 复制公钥内容，添加到 GitHub
GitHub路径：Settings → SSH and GPG keys → New SSH key
4. 测试连接
ssh -T git@github.com
显示 Hi 用户名! You've successfully authenticated 即为配置成功。
三、创建博客专属仓库
1. GitHub首页点击右上角 + → New repository
2. 仓库名严格填写：yangzhaozhou.github.io
3. 勾选 Add a README file，仓库权限选择Public（公开）
4. 点击 Create repository 创建仓库
3.1 开启 GitHub Pages 服务
1. 进入仓库 → Settings → Pages
2. Build and deployment 配置：
- Source：Deploy from a branch
- Branch：main
- Folder：/ (root) 根目录
3. 点击 Save，等待1-3分钟部署生效
部署成功后会显示站点访问地址。
3.2 克隆仓库到本地
git clone git@github.com:yangzhaozhou/yangzhaozhou.github.io.git
cd yangzhaozhou.github.io
四、初始化 Jekyll 博客基础架构
GitHub Pages 原生支持 Jekyll 框架，无需手动部署，支持Markdown、分类、标签、自动渲染，是程序员博客首选方案。
4.1 创建博客核心目录文件
在博客根目录创建以下文件/文件夹，固定结构无需修改：
yangzhaozhou.github.io/
├── _layouts/        # 文章布局模板文件夹
│   └── post.html    # 统一文章页面布局（含评论、样式）
├── _posts/          # 所有博客文章存放目录（必须）
├── _config.yml      # 博客全局配置文件
└── index.html       # 博客首页（展示所有文章、分类标签）
4.2 配置全局文件 _config.yml
根目录新建 _config.yml，粘贴以下配置：
# 博客基础信息
title: ZYZ的技术博客
author: ZYZ
description: 后端开发 | 编程技术 | 学习笔记 | 实战教程
# 站点地址
url: https://yangzhaozhou.github.io
# 时区配置
timezone: Asia/Shanghai
# 开启文章分类标签功能
defaults:
  - scope:
      path: ""
      type: posts
    values:
      layout: post

五、集成 Giscus 免费评论功能
采用 GitHub Discussions 实现评论功能，免费无广告、程序员专属、数据自主可控。
5.1 开启仓库 Discussions
仓库 → Settings → General → Features → 勾选 Discussions
5.2 安装 Giscus 应用
1. 访问官网：https://github.com/apps/giscus
2. 点击 Install，授权选中 yangzhaozhou.github.io 仓库
5.3 生成专属评论代码
1. 访问：https://giscus.app/zh-CN
2. 配置参数：
- 仓库：yangzhaozhou/yangzhaozhou.github.io
- 页面映射：pathname
- 分类：General
- 主题：light（浅色）/dark（深色）
- 语言：zh-CN
3. 复制生成的完整 script 代码，替换掉 post.html 中原有的默认评论代码
六、博客发文规范（必须遵守）
6.1 文章存放位置
所有 Markdown 文章必须放在根目录 _posts 文件夹内。
6.2 文件名强制格式
固定格式：年-月-日-自定义标题.md
示例：2026-05-25-github-blog-build.md
6.3 文章头部模板（通用）
每篇文章开头必须添加以下配置，否则分类、标签、布局不生效：
---
title: 文章自定义标题
date: 2026-05-25
layout: post
categories: 分类名称
tags: 标签1 标签2 标签3
---

这里书写Markdown正文内容，支持代码块、标题、列表、图片、公式等语法
⚠️ 规则：categories 仅填1个分类，tags 可填多个，空格分隔
七、博客发布推送流程
写完文章后，终端进入博客根目录，执行以下命令发布上线：
git add .
git commit -m "新增/更新文章：xxx"
git push origin main
等待 1-3 分钟 GitHub 自动部署，刷新博客地址即可看到更新内容。
八、推荐好用的 Markdown 编辑器
1. VS Code（首选、免费、程序员标配）
搭配插件：Markdown All in One、Markdown Preview Enhanced，支持实时预览、代码格式化、Git联动。
2. MarkText（免费开源）
Typora 平替，所见即所得，界面简洁，适合专注写作。
3. Obsidian（知识库首选）
支持双向链接、本地存储，可长期积累技术笔记与博客文章。
九、常见问题排查
- 博客404：检查仓库名是否与用户名一致、仓库是否公开、Pages分支是否为main根目录
- 分类标签不显示：检查文章头部是否填写对应配置、是否指定 layout: post
- 评论区不加载：检查Discussions是否开启、Giscus是否授权、代码是否替换为自己的专属代码
- 更新不生效：清空浏览器缓存，等待1-3分钟GitHub部署完成
